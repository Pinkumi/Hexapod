# Cámara CSI

`CameraService` mantiene una única instancia Picamera2 y un worker que conserva el último JPEG para todos los clientes de `/stream.mjpg`. La API expone inicio, apagado, estado y cambios de tamaño/calidad/rotación. La cámara es opcional: si Picamera2 o el dispositivo no están accesibles, el servicio permanece operativo y devuelve el error en `/api/camera/status`. Detenerla libera el recurso. La IA está separada y aún no configurada.

En Raspberry Pi OS Lite, instala Picamera2 con paquetes del sistema (`sudo apt install python3-picamera2 --no-install-recommends`). El entorno `.venv` está configurado para heredar paquetes del sistema (`include-system-site-packages = true`). Raspberry Pi recomienda la instalación mediante `apt` para conservar compatibilidad con libcamera; consulta [la documentación oficial de cámara](https://www.raspberrypi.com/documentation/accessories/camera-software.html) y [Picamera2](https://github.com/raspberrypi/picamera2). No se pudo validar cámara ni Picamera2 desde el entorno de desarrollo actual. Rutas permitidas: 640×480, 1296×972 y 1920×1080; validar el modo exacto contra `rpicam-hello --list-cameras` en el dispositivo antes de usar resoluciones superiores.
